## အင်္ဂါရပ်များ

- **ဖန်သားပြင်၊ window၊ နယ်မြေ သို့မဟုတ် မောက်စ်ပတ်လည်။** ဖန်သားပြင်တစ်ခု၊ window တစ်ခု၊ ဆွဲထုတ်ထားသော စတုဂံတစ်ခု၊ သို့မဟုတ် ကာဆာကို လိုက်သော frame တစ်ခုကို ရိုက်ကူးပါ။ 16:9၊ 4:3၊ 1:1 သို့မဟုတ် 9:16။
- **မည်သည့် frame rate မဆို။** ဖန်သားပြင်၏ refresh rate ဖြင့် ဘယ်တော့မှ မကန့်သတ်ပါ: အခမဲ့ဖြင့် 1080p နှင့် 60 fps အထိ၊ အပြည့်အစုံဗားရှင်းဖြင့် 4K နှင့် 240 fps အထိ။
- **PC အသံနှင့် မိုက်ခရိုဖုန်း** တူညီသော clock ပေါ်တွင်၊ noise reduction၊ push-to-talk၊ သီးခြား volume slider များဖြင့်၊ နှင့် လိုသလို နှစ်ခုကို WAV ဖိုင် သီးခြားစီ သိမ်းနိုင်သည်။
- **ဖိုင်ငယ်များ၊ သို့မဟုတ် lossless။** Small၊ Balanced၊ High သို့မဟုတ် Indistinguishable အရည်အသွေးဖြင့် hardware-encoded MP4၊ သို့မဟုတ် Lossless: pixel တိုင်းကို တိကျစွာ MKV ဖိုင်တွင်။ H.264 အခမဲ့; HEVC နှင့် AV1 အပြည့်အစုံဗားရှင်းဖြင့်။
- **လင့်ခ် မျှဝေပါ။** Myna Cloud ကို ဖွင့်ထားလျှင် ရပ်လိုက်သည်နှင့် လင့်ခ်သည် သင့် clipboard တွင် ရောက်ရှိနေပြီး ဗီဒီယိုသည် နောက်ခံတွင် အပ်လုဒ်လုပ်သည်။
- **ရိုက်ကူးနေစဉ် ရေးဆွဲပါ:** ဘောပင်၊ highlighter၊ မျဉ်းများ၊ မြှားများ၊ ပုံသဏ္ဍာန်များ၊ နံပါတ်ရိုက်ထားသော အဆင့်များ၊ စာသားနှင့် whiteboard။
- **ကလစ်များနှင့် shortcut များ ပြပါ:** click ring များ၊ ကာဆာ glow နှင့် Ctrl+C ကဲ့သို့ shortcut များကို ခဏ ဖန်သားပြင်ပေါ်တွင် ပြသည်။
- **Instant replay:** နောက်ဆုံး 5 စက္ကန့်မှ 3 မိနစ်အထိ အဆင်သင့်ထားပြီး ခလုတ်တစ်ခုဖြင့် သိမ်းနိုင်သည်။
- **ဖြတ်တောက်ခြင်း၊ ဖြတ်ခြင်းနှင့် GIF:** re-encode မလုပ်ဘဲ ဖြတ်တောက်ပါ၊ နယ်မြေသို့ ဖြတ်ပါ၊ 8၊ 25 သို့မဟုတ် 50 MB သို့ ချုံ့ပါ၊ သို့မဟုတ် ကလစ်ကို GIF အဖြစ် ပြောင်းပါ။
- **ဖန်သားပြင်ဓာတ်ပုံများ** (PNG၊ JPG၊ BMP)၊ **အသံသက်သက်** (M4A သို့မဟုတ် WAV)၊ **webcam overlay**၊ **စာသားနှင့် logo overlay များ**။
- **ဘာသာစကား 25 မျိုး** နှင့် screen reader များနှင့် အလုပ်လုပ်သော ထိန်းချုပ်မှုများ။
