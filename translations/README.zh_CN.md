## 功能特点

- **整个屏幕、单个窗口、自定区域，或跟随鼠标的画面。** 可录制一个屏幕、一个窗口、你拖出的矩形区域，或随指针移动的取景框。可选 16:9、4:3、1:1 或 9:16。
- **任意帧率。** 不受屏幕刷新率限制：免费版最高 1080p 60 fps，完整版最高 4K 240 fps。
- **电脑声音与麦克风**在同一时间轴上录制，支持降噪、按键说话、独立音量滑块，并可选择将两者分别保存为 WAV 文件。
- **文件小巧，或无损画质。** 可选小、均衡、高或无差别画质，以硬件编码的 MP4 输出；或选择无损：逐像素精确，保存为 MKV 文件。H.264 免费；HEVC 和 AV1 需完整版。
- **分享链接。** 开启 Myna Cloud 后，停止录制时链接即刻复制到剪贴板；录像会在后台上传。
- **录制时可绘图：** 画笔、荧光笔、直线、箭头、形状、编号步骤、文字和白板。
- **显示点击与快捷键：** 点击圆环、指针光晕，并短暂显示 Ctrl+C 等快捷键。
- **即时回放：** 保留最近 5 秒至 3 分钟的内容，随时一键保存。
- **修剪、裁剪与 GIF：** 无需重新编码即可修剪，裁剪到指定区域，压缩到 8、25 或 50 MB，或将片段转换为 GIF。
- **截图**（PNG、JPG、BMP）、**仅录音**（M4A 或 WAV）、**摄像头叠加**、**文字和标志叠加**。
- **78 种语言**，并支持屏幕阅读器操作。
