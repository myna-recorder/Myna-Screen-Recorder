## 기능

- **화면, 창, 영역 또는 마우스 주변.** 화면 하나, 창 하나, 드래그해서 그린 사각형, 또는 포인터를 따라가는 프레임을 녹화합니다. 16:9, 4:3, 1:1 또는 9:16.
- **원하는 프레임 속도.** 화면 주사율에 묶이지 않습니다. 무료로 1080p 60 fps까지, 전체 버전으로 4K 240 fps까지.
- **PC 소리와 마이크**를 같은 시계로 녹음합니다. 노이즈 감소, 푸시투토크, 별도의 볼륨 슬라이더를 지원하며, 원하면 두 소리를 별도의 WAV 파일로 저장할 수 있습니다.
- **작은 파일 또는 무손실.** 소형, 균형, 고품질, 구분 불가 품질의 하드웨어 인코딩 MP4, 또는 모든 픽셀이 정확한 MKV 파일의 무손실. H.264는 무료, HEVC와 AV1은 전체 버전에서 사용할 수 있습니다.
- **링크 공유.** Myna Cloud를 켜면 녹화를 멈추는 순간 링크가 클립보드에 복사되고, 녹화 파일은 백그라운드에서 업로드됩니다.
- **녹화하면서 그리기:** 펜, 형광펜, 선, 화살표, 도형, 번호 단계, 텍스트, 화이트보드.
- **클릭과 단축키 표시:** 클릭 링, 포인터 글로우, 그리고 Ctrl+C 같은 단축키를 잠시 화면에 표시.
- **즉시 재생:** 최근 5초에서 3분까지 준비해 두고, 키 하나로 저장합니다.
- **자르기, 영역 자르기, GIF:** 재인코딩 없이 자르기, 영역으로 자르기, 8, 25 또는 50MB로 줄이기, 클립을 GIF로 만들기.
- **스크린샷**(PNG, JPG, BMP), **오디오 전용**(M4A 또는 WAV), **웹캠 오버레이**, **텍스트 및 로고 오버레이**.
- **78개 언어**, 화면 낭독기와 함께 쓸 수 있는 조작 방식.
