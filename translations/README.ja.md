## 機能

- **画面、ウィンドウ、範囲、またはマウス周辺。** 1 つの画面、1 つのウィンドウ、ドラッグで指定した矩形、またはポインターに追従する枠を録画できます。16:9、4:3、1:1、9:16 に対応。
- **任意のフレーム レート。** ディスプレイのリフレッシュ レートに制限されません。無料版は 1080p・60 fps まで、フル版は 4K・240 fps まで。
- **PC のサウンドとマイク** を同じクロックで記録。ノイズ抑制、プッシュ トゥ トーク、個別の音量スライダーに対応し、お好みで 2 つを別々の WAV ファイルとして保存できます。
- **小さいファイル、またはロスレス。** 小、バランス、高、区別不能の画質をハードウェア エンコードの MP4 で、またはロスレス（すべてのピクセルが正確な MKV ファイル）で選べます。H.264 は無料。HEVC と AV1 はフル版で利用できます。
- **リンクを共有。** Myna Cloud をオンにすると、停止した瞬間にリンクがクリップボードにコピーされ、録画はバックグラウンドでアップロードされます。
- **録画しながら描画:** ペン、蛍光ペン、線、矢印、図形、番号付きステップ、テキスト、ホワイトボード。
- **クリックとショートカットを表示:** クリック リング、ポインターの光彩、Ctrl+C などのショートカットを一時的に画面に表示。
- **インスタント リプレイ:** 直近 5 秒から 3 分間を保持し、1 つのキーで保存できます。
- **トリム、切り抜き、GIF:** 再エンコードせずにトリム、領域に切り抜き、8、25、50 MB に縮小、またはクリップを GIF に変換。
- **スクリーンショット**（PNG、JPG、BMP）、**音声のみ**（M4A または WAV）、**ウェブカメラ オーバーレイ**、**テキストとロゴのオーバーレイ**。
- **78 言語に対応**、スクリーン リーダーで操作できます。
