## Онцлогууд

- **Дэлгэц, цонх, талбай эсвэл хулганы эргэн тойронд.** Нэг дэлгэц, нэг цонх, таны чирж гаргасан тэгш өнцөгт, эсвэл заагчийг дагах хүрээг бичнэ. 16:9, 4:3, 1:1 эсвэл 9:16.
- **Ямар ч кадрын хурд.** Дэлгэцийн сэргээх давтамжаар хэзээ ч хязгаарлагддаггүй: үнэгүйгээр 60 fps-ээр 1080p хүртэл, бүрэн хувилбартай 240 fps-ээр 4K хүртэл.
- **PC-ийн дуу ба микрофон** нэг цагт, дуу багасгах, товчлуур дарж ярих, тусдаа дууны гулсуур бүхий; хүсвэл хоёуланг нь тусдаа WAV файл болгон хадгалж болно.
- **Жижиг файл эсвэл алдагдалгүй.** Жижиг, Тэнцвэртэй, Өндөр эсвэл Ялгагдахгүй чанартай, техник хангамжаар кодлогдсон MP4, эсвэл Алдагдалгүй: пиксел бүр яг таарсан, MKV файлд. H.264 үнэгүй; HEVC ба AV1 бүрэн хувилбартай.
- **Линк хуваалцах.** Myna Cloud-ийг асаахад зогсоох мөчид линк таны түр санах ойд байна; бичлэг арын горимд байршуулагдана.
- **Бичлэг хийж байхдаа зур:** үзэг, тодруулагч, шугам, сум, хэлбэр, дугаарласан алхам, текст, цагаан самбар.
- **Дарсан товч ба товчлолуудыг харуул:** дарсны цагираг, заагчийн гэрэл, Ctrl+C гэх мэт товчлолууд хэсэг хугацаанд дэлгэц дээр.
- **Шууд дахин тоглуулах:** сүүлийн 5 секундээс 3 минут хүртэлх бичлэгийг бэлэн байлгаж, нэг товчоор хадгална.
- **Тайрах, хайчлах, GIF:** дахин кодлохгүйгээр тайрах, талбайд хайчлах, 8, 25 эсвэл 50 MB хүртэл багасгах, эсвэл клипийг GIF болгох.
- **Дэлгэцийн зураг** (PNG, JPG, BMP), **зөвхөн дуу** (M4A эсвэл WAV), **вебкамерын давхарга**, **текст ба логоны давхарга**.
- **78 хэл** болон дэлгэцийн уншигчтай ажилладаг удирдлага.
