## លក្ខណៈពិសេស

- **អេក្រង់ វិនដូ តំបន់ ឬជុំវិញកណ្តុរ។** ថតអេក្រង់មួយ វិនដូមួយ ចតុកោណដែលអ្នកអូស ឬស៊ុមដែលដើរតាមកណ្តុរ។ 16:9, 4:3, 1:1 ឬ 9:16។
- **ល្បឿនហ្វ្រេមណាក៏បាន។** មិនដែលកំណត់ដោយល្បឿនបន្ទាត់ធាតុ (refresh rate) នៃអេក្រង់ទេ៖ ឥតគិតថ្លៃរហូតដល់ 1080p នៅ 60 fps, ជាមួយកំណែពេញលេញរហូតដល់ 4K នៅ 240 fps។
- **សំឡេងកុំព្យូទ័រ និងមីក្រូហ្វូន** នៅលើនាឡិកាតែមួយ ជាមួយការកាត់សំឡេងរំខាន ចុចនិយាយ កម្រិតសំឡេងដាច់ដោយឡែក ហើយអាចរក្សាទុកទាំងពីរជាឯកសារ WAV ដាច់ដោយឡែកបើចង់។
- **ឯកសារតូច ឬគ្មានការបាត់បង់។** Small, Balanced, High ឬ Indistinguishable ជា MP4 អ៊ិនកូដដោយផ្នែករឹង ឬ Lossless៖ ពិកសែលនីមួយៗត្រឹមត្រូវ ក្នុងឯកសារ MKV។ H.264 ឥតគិតថ្លៃ; HEVC និង AV1 ជាមួយកំណែពេញលេញ។
- **ចែករំលែកតំណភ្ជាប់។** បើក Myna Cloud ហើយតំណភ្ជាប់នឹងស្ថិតក្នុងឃ្លីបបត (clipboard) ភ្លាមៗនៅពេលឈប់; ការថតនឹងផ្ទុកឡើងនៅផ្ទៃខាងក្រោយ។
- **គូរខណៈពេលថត៖** ប៊ិច ឧស្ម័ន ខ្សែ ព្រួញ រាង ជំហានលេខ អក្សរ និងក្តារសរសេរ។
- **បង្ហាញការចុច និងផ្លូវកាត់៖** វង់ចុច ពន្លឺកណ្តុរ និងផ្លូវកាត់ដូចជា Ctrl+C បង្ហាញលើអេក្រង់មួយភ្លែត។
- **ចាក់ឡើងវិញភ្លាមៗ៖** រក្សាទុក 5 វិនាទីចុងក្រោយ ដល់ 3 នាទី ហើយរក្សាទុកដោយប៊ូតុងតែមួយ។
- **កាត់ ឆ្លាក់ និង GIF៖** កាត់ដោយមិនអ៊ិនកូដឡើងវិញ ឆ្លាក់ទៅតំបន់ បង្រួមទៅ 8, 25 ឬ 50 MB ឬបំប្លែងវីដេអូខ្លីទៅជា GIF។
- **រូបថតអេក្រង់** (PNG, JPG, BMP), **សំឡេងតែប៉ុណ្ណោះ** (M4A ឬ WAV), **កាមេរ៉ាបណ្តាញ**, **ស្ទីកឃ័ររបស់អក្សរ និងឡូហ្គោ**។
