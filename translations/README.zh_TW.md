## 功能

- **螢幕、視窗、區域或滑鼠周圍。** 錄製單一螢幕、單一視窗、您拖曳框選的矩形，或跟隨游標移動的畫框。支援 16:9、4:3、1:1 或 9:16。
- **任意影格率。** 不會受限於螢幕的更新率：免費版最高 1080p 60 fps，完整版最高 4K 240 fps。
- **電腦音效與麥克風**使用同一時脈錄製，並提供降噪、按住說話、各自獨立的音量滑桿；如有需要，也可將兩者分別存為 WAV 檔。
- **小檔案，或無損畫質。** 可選擇小型、平衡、高或難以分辨的硬體編碼 MP4 畫質，或無損：每個像素都完全精確，儲存為 MKV 檔。H.264 免費；HEVC 與 AV1 需使用完整版。
- **分享連結。** 開啟 Myna Cloud 後，停止錄製時連結會立即複製到剪貼簿；錄影會在背景上傳。
- **錄製時繪圖：** 畫筆、螢光筆、直線、箭頭、形狀、編號步驟、文字與白板。
- **顯示點擊與快捷鍵：** 點擊漣漪、游標光暈，以及 Ctrl+C 等快捷鍵會在螢幕上短暫顯示。
- **即時重播：** 保留最近 5 秒至 3 分鐘的內容，隨時可用一個按鍵儲存。
- **剪輯、裁切與 GIF：** 不重新編碼即可剪輯、裁切為指定區域、壓縮至 8、25 或 50 MB，或將片段轉為 GIF。
- **螢幕擷取畫面**（PNG、JPG、BMP）、**純音訊**（M4A 或 WAV）、**網路攝影機疊加**、**文字與標誌疊加**。
- **78 種語言**，且控制項支援螢幕閱讀器。
