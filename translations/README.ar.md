## الميزات

- **الشاشة، أو النافذة، أو منطقة، أو حول الماوس.** سجّل شاشة واحدة، أو نافذة واحدة، أو مستطيلاً ترسمه بالسحب، أو إطاراً يتبع المؤشر. 16:9 أو 4:3 أو 1:1 أو 9:16.
- **أي معدل إطارات.** غير مقيّد بمعدل تحديث شاشتك أبداً: حتى 1080p بـ60 fps مجاناً، وحتى 4K بـ240 fps مع النسخة الكاملة.
- **صوت الكمبيوتر والميكروفون** على التوقيت نفسه، مع تقليل الضوضاء، والتحدث بالضغط (push-to-talk)، ومنزلقات مستوى صوت منفصلة، ويمكن حفظ الاثنين كملفين منفصلين بصيغة WAV إن شئت.
- **ملفات صغيرة، أو بلا فقد.** جودة صغيرة، أو متوازنة، أو عالية، أو لا يمكن تمييزها كملف MP4 مُشفَّر بالعتاد، أو بلا فقد: كل بكسل دقيق، في ملف MKV. H.264 مجاناً؛ وHEVC وAV1 مع النسخة الكاملة.
- **شارك رابطاً.** فعّل Myna Cloud وسيكون الرابط في الحافظة لحظة إيقاف التسجيل؛ ويُرفع التسجيل في الخلفية.
- **ارسم أثناء التسجيل:** قلم، وقلم تمييز، وخطوط، وأسهم، وأشكال، وخطوات مرقّمة، ونص، ولوحة بيضاء.
- **أظهر النقرات والاختصارات:** حلقات النقر، ووهج المؤشر، واختصارات مثل Ctrl+C تظهر على الشاشة لحظة.
- **إعادة تشغيل فورية:** احتفظ بآخر 5 ثوانٍ إلى 3 دقائق جاهزة، واحفظها بمفتاح واحد.
- **قص واقتصاص وGIF:** قص دون إعادة ترميز، واقتصص منطقة، وصغّر إلى 8 أو 25 أو 50 ميغابايت، أو حوّل مقطعاً إلى GIF.
- **لقطات شاشة** (PNG وJPG وBMP)، و**صوت فقط** (M4A أو WAV)، و**طبقة كاميرا الويب**، و**طبقات نص وشعار**.
- **78 لغة**، وعناصر تحكم تعمل مع قارئات الشاشة.
