## תכונות

- **מסך, חלון, אזור או סביב העכבר.** הקליטו מסך אחד, חלון אחד, מלבן שאתם גוררים, או מסגרת שעוקבת אחרי הסמן. 16:9, 4:3, 1:1 או 9:16.
- **כל קצב פריימים.** לעולם לא מוגבל לקצב הרענון של המסך: עד 1080p ב-60 fps בחינם, ועד 4K ב-240 fps בגרסה המלאה.
- **צליל מהמחשב ומהמיקרופון** על אותו שעון, עם הפחתת רעשים, דיבור בלחיצה (push-to-talk), מחוונים נפרדים לעוצמה, ואפשר לשמור את השניים כקבצי WAV נפרדים.
- **קבצים קטנים, או ללא אובדן.** איכות Small, Balanced, High או Indistinguishable כ-MP4 עם קידוד חומרה, או Lossless: כל פיקסל מדויק, בקובץ MKV. H.264 בחינם; HEVC ו-AV1 בגרסה המלאה.
- **שתפו קישור.** הפעילו את Myna Cloud, והקישור יועתק ללוח ברגע שתעצרו; ההקלטה מועלית ברקע.
- **ציירו תוך כדי הקלטה:** עט, מרקר, קווים, חיצים, צורות, שלבים ממוספרים, טקסט ולוח לבן.
- **הציגו לחיצות וקיצורי מקלדת:** טבעות לחיצה, זוהר סביב הסמן, וקיצורים כמו Ctrl+C שמוצגים על המסך לרגע.
- **שידור חוזר מיידי:** שמרו מוכנים את 5 השניות עד 3 הדקות האחרונות ושמרו אותן בלחיצת מקש אחת.
- **חיתוך, חיתוך לאזור ו-GIF:** חתכו בלי קידוד מחדש, חתכו לאזור, כווצו ל-8, 25 או 50 MB, או הפכו קליפ ל-GIF.
- **צילומי מסך** (PNG, JPG, BMP), **שמע בלבד** (M4A או WAV), **שכבת מצלמת אינטרנט**, **שכבות טקסט ולוגו**.
- **25 שפות**, ובקרות שעובדות עם קוראי מסך.

קבלו את הגרסה האחרונה מ[דף ההורדה](https://mynarecorder.com/screen-recorder/download) או מ[Releases](https://github.com/myna-recorder/Myna-Screen-Recorder/releases) בדף הזה: ה**מתקין**, או קובץ ה**עצמאי** (standalone) שרץ בלי התקנה.

כשפותחים את הקובץ, Windows עשוי להציג "Windows הגן על המחשב שלך". בחרו **מידע נוסף**, ואז **הפעל בכל זאת**.

**דרישות:** Windows 10 (גרסה 2004 ומעלה) או Windows 11, 64 סיביות, וכרטיס גרפי התומך ב-Direct3D 11.
