## ഫീച്ചറുകൾ

- **സ്ക്രീൻ, വിൻഡോ, ഏരിയ അല്ലെങ്കിൽ മൗസിന് ചുറ്റും.** ഒരു സ്ക്രീൻ, ഒരു വിൻഡോ, നിങ്ങൾ വലിച്ചെടുക്കുന്ന ഒരു ചതുരം, അല്ലെങ്കിൽ പോയിന്റർ പിന്തുടരുന്ന ഒരു ഫ്രെയിം റെക്കോർഡ് ചെയ്യുക. 16:9, 4:3, 1:1 അല്ലെങ്കിൽ 9:16.
- **ഏത് ഫ്രെയിം റേറ്റും.** സ്ക്രീനിന്റെ റിഫ്രഷ് റേറ്റിൽ ഒരിക്കലും പരിമിതപ്പെടുത്തില്ല: സൗജന്യമായി 60 fps-ൽ 1080p വരെ, പൂർണ്ണ പതിപ്പിനൊപ്പം 240 fps-ൽ 4K വരെ.
- **PC ശബ്ദവും മൈക്രോഫോണും** ഒരേ ക്ലോക്കിൽ, നോയ്സ് റിഡക്ഷൻ, പുഷ്-ടു-ടോക്ക്, പ്രത്യേക വോളിയം സ്ലൈഡറുകൾ എന്നിവയോടെ; ആവശ്യമെങ്കിൽ രണ്ടും പ്രത്യേക WAV ഫയലുകളായി സംരക്ഷിക്കാം.
- **ചെറിയ ഫയലുകൾ, അല്ലെങ്കിൽ നഷ്ടരഹിതം.** ചെറിയ, സന്തുലിതം, ഉയർന്നത് അല്ലെങ്കിൽ വേർതിരിച്ചറിയാനാകാത്തത് എന്ന ഗുണനിലവാരത്തിൽ ഹാർഡ്‌വെയർ-എൻകോഡ് ചെയ്ത MP4 ആയി, അല്ലെങ്കിൽ നഷ്ടരഹിതം: ഓരോ പിക്സലും കൃത്യം, MKV ഫയലിൽ. H.264 സൗജന്യം; HEVC, AV1 പൂർണ്ണ പതിപ്പിനൊപ്പം.
- **ഒരു ലിങ്ക് പങ്കിടുക.** Myna Cloud ഓണാക്കുക, നിർത്തുന്ന നിമിഷം ലിങ്ക് ക്ലിപ്പ്ബോർഡിൽ ഉണ്ടാകും; റെക്കോർഡിംഗ് പശ്ചാത്തലത്തിൽ അപ്‌ലോഡ് ചെയ്യപ്പെടും.
- **റെക്കോർഡ് ചെയ്യുമ്പോൾ വരയ്ക്കുക:** പേന, ഹൈലൈറ്റർ, വരകൾ, അമ്പടയാളങ്ങൾ, രൂപങ്ങൾ, നമ്പർ ഇട്ട ഘട്ടങ്ങൾ, ടെക്സ്റ്റ്, വൈറ്റ്ബോർഡ്.
- **ക്ലിക്കുകളും ഷോർട്ട്കട്ടുകളും കാണിക്കുക:** ക്ലിക്ക് റിങ്ങുകൾ, പോയിന്റർ ഗ്ലോ, Ctrl+C പോലുള്ള ഷോർട്ട്കട്ടുകൾ കുറച്ചുനേരം സ്ക്രീനിൽ.
- **തൽക്ഷണ റീപ്ലേ:** അവസാനത്തെ 5 സെക്കൻഡ് മുതൽ 3 മിനിറ്റ് വരെ തയ്യാറാക്കി വയ്ക്കുകയും ഒരു കീ കൊണ്ട് സംരക്ഷിക്കുകയും ചെയ്യാം.
- **ട്രിം, ക്രോപ്പ്, GIF:** വീണ്ടും എൻകോഡ് ചെയ്യാതെ ട്രിം ചെയ്യുക, ഒരു ഏരിയയിലേക്ക് ക്രോപ്പ് ചെയ്യുക, 8, 25 അല്ലെങ്കിൽ 50 MB വരെ ചുരുക്കുക, അല്ലെങ്കിൽ ഒരു ക്ലിപ്പ് GIF ആക്കുക.
- **സ്ക്രീൻഷോട്ടുകൾ** (PNG, JPG, BMP), **ഓഡിയോ മാത്രം** (M4A അല്ലെങ്കിൽ WAV), **വെബ്‌ക്യാം ഓവർലേ**, **ടെക്സ്റ്റ്, ലോഗോ ഓവർലേകൾ**.
